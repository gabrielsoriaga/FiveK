🏃 FiveK – User Guide

This app helps you track your runs, earn points, and stay consistent with your fitness goals.

Getting Started
Creating an account

When you first open the app, you’ll need to sign up.

Just enter:

a username
your email
a password

If everything’s valid, you’ll be taken straight to the home screen.
If something’s missing or the email is already used, the app will tell you.

Logging in

Already have an account? Just log in with your email and password.

If your details are wrong, you’ll see an error message.

Navigation

At the bottom of the app, you’ll see 3 main tabs:

Home → where your activity shows up
Record → where you track your run
Profile → your stats, achievements, and info
Home Screen

This is your main dashboard.

Here you can see:

the current date and time
your recent runs
your streak (if you’ve been consistent)

If you’ve been active for a few days in a row, you’ll see a streak message pop up.

Recording a Run
Step 1: Open Record

Tap the Record button.

Step 2: Allow location

The app will ask for GPS access.
You need to allow this for tracking to work.

If allowed → map loads and tracking works
If denied → you won’t be able to track properly
Step 3: Start tracking

Press Start to begin.

You’ll see:

time running
distance
pace
Step 4: During your run

You can:

Pause → stops tracking temporarily
Resume → continues
Stop → ends the run

(there’s a small issue where resume might slightly mess up distance tracking sometimes)

Step 5: After finishing

Once you stop, you’ll get a summary.

You can:

give your run a title
add a short note

Then choose:

Save → keeps the run and updates your stats
Discard → removes the run (points may still count)
Points System

You earn points based on how far you run:

under 1 km → 0 points
1 km → 100 points
2.5 km → 200 points
5 km → 500 points
Streaks

If you run consistently (3+ days in a row), you’ll unlock a streak.

Streaks give you:

2x points multiplier
Challenges

You can access challenges from the Record page.

There are different levels:

bronze
silver
gold

Some challenges are locked until you reach a certain level.

Complete them to earn extra points.

Profile

Your profile shows everything about your progress.

You can see:

your level
total points
achievements
weekly stats

You can also:

edit your bio
unlock titles as you level up
Weekly Progress

Shows your average:

time
distance

Plus a graph of your activity.

Logging out

Tap the logout button and you’ll be taken back to the login screen.

Notes
GPS needs to be enabled for tracking
Some features (like challenges) unlock as you progress
There’s a minor issue with resume tracking accuracy
